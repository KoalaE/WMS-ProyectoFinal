# WMS Frontend

React + Vite, organizado por **módulos** (igual que el backend).

```
src/
├── app/                    # Entrada: main.tsx, App.tsx, rutas
├── modules/
│   ├── auth/               # Login y sesión demo
│   ├── layout/             # Sidebar y shell
│   ├── dashboard/
│   ├── productos/
│   ├── movimientos/
│   ├── inventario/
│   └── reportes/
└── shared/                 # API client, tablas, tipos, estilos
    ├── api/
    ├── components/
    ├── types/
    ├── utils/
    └── styles/
```

```bash
npm install
npm run dev
```
